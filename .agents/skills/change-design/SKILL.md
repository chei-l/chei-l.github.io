# 사이트 디자인 바꾸기 마법 지침서

이 스킬은 블로그의 전체 레이아웃이나 글 내용은 그대로 유지하면서, 색상이나 글씨체 같은 디자인 스타일을 아주 과감하게 바꿀 때 사용합니다. 

초등학생 친구가 원하는 스타일을 말하면, 에이전트가 즉석에서 세상에 단 하나뿐인 새로운 디자인을 만들어 적용합니다.

사용자가 초등학생 친구이므로, 모든 대화 and 설명은 반드시 **아주 쉽고 친근한 한글**로 해야 합니다.

---

## 중요 규칙 (꼭 지켜야 해요!)

1. **그라데이션 금지**: 디자인을 바꿀 때 `linear-gradient`나 `radial-gradient` 같은 흐릿하게 변하는 색상 효과는 절대 쓰지 않습니다. 오직 쨍하고 명확한 **단색(Solid Color)**만 사용합니다.
2. **이모지 금지**: 대화 내용, 디자인 결과물, 클래스 이름, CSS 등 모든 곳에 꽃, 네온, 눈사람 같은 이모지 문자(예: 🌸, 🌌, ❄️, 👾, 🔥)를 절대 넣지 않습니다. 텍스트로만 예쁘게 표현합니다.
3. **과감한 디자인 시도**: 평범하고 무난한 디자인 대신, 보더(테두리)를 아주 굵게 하거나 장난감 블록처럼 쨍한 색대비를 주는 등 개성이 뚜렷하고 멋진 스타일을 만듭니다.

---

## 에이전트의 실행 순서

### 1단계: 초등학생 친구에게 의견 물어보기
초등학생 친구에게 "네 블로그를 어떤 색깔이나 느낌으로 바꾸고 싶어? 좋아하는 장난감이나 좋아하는 색깔을 마음껏 이야기해줘!"라고 다정하게 물어봅니다.

* 예시: "소방차처럼 쨍한 빨간색 테마", "바나나처럼 노란색에 까만 글씨", "민트 초코처럼 시원한 색" 등 자유롭게 말하도록 유도합니다.

### 2단계: 어울리는 색상과 변수 직접 만들기 (프리셋 없음)
초등학생 친구의 요청을 바탕으로, 아래 규칙에 따라 `:root` CSS 변수를 즉석에서 창조합니다.

* **배경색과 텍스트색 결정**: 눈이 아프지 않으면서도 대비가 뚜렷해야 합니다.
  - 어두운 배경일 때: 아주 어두운 단색 배경에 완전한 하얀색 글씨를 씁니다.
  - 밝은 배경일 때: 아주 연한 파스텔 단색 배경에 완전한 검은색 글씨를 씁니다.
* **포인트 색상(액센트) 결정**: 초등학생 친구가 말한 핵심 색상을 아주 쨍한 단색으로 선정하여 적용합니다. (그라데이션은 절대 사용하지 않습니다.)
* **테두리와 그림자**: 과감한 느낌을 주기 위해 테두리 두께(`border-width`)를 늘리거나, 투명도가 없는 진한 검정색/포인트색 그림자를 사용합니다. (예: `box-shadow: 4px 4px 0px #000000;`)

### 3단계: CSS 스타일 교체하기
결정한 단색 테마 값들을 `static/css/style.css`의 `:root` 부분에 대입합니다.
이때 기존 파일에 남아있는 `radial-gradient` 배경(`body::before`)과 텍스트 그라데이션 등을 전부 지우고 단색(`background: var(--color-bg);` 등)으로 깔끔하게 정리합니다.

### 4단계: 폰트 교체하기 (선택 사항)
초등학생 친구가 말한 분위기에 딱 맞는 멋진 영문/한글 폰트가 필요하다면, `templates/base.html` 파일의 `<head>` 태그 안에 구글 폰트 링크를 주입합니다.

### 5단계: 직접 확인하기
변경이 끝났다면 터미널에 아래 명령어를 실행하여 로컬 컴퓨터에서 사이트를 띄워줍니다.
```bash
hwaro serve --open
```
초등학생 친구의 인터넷 창에 블로그가 열리면, 스타일이 깨지지 않았는지 함께 확인하고 완료합니다.

## AI 에이전트를 위한 CSS 변수 맵핑 가이드

즉석에서 테마를 생성할 때 아래 CSS 변수들의 관계를 생각하며 값을 채워 넣으세요:

* `--color-bg`: 전체 배경색 (단색 지정)
* `--color-bg-soft`: 헤더나 카드 요소의 배경색 (배경색보다 살짝 밝거나 어둡게 단색 지정)
* `--color-surface`: 포스트 내용 박스 등의 배경색
* `--color-border`: 기본 테두리 색상 (경계선이 뚜렷하게 보이도록 명확한 단색 지정)
* `--color-border-hover`: 마우스를 올렸을 때 반짝이거나 바뀌는 테두리 색상
* `--color-text`: 기본 본문 글자 색상
* `--color-text-light`: 조금 덜 강조되는 글자 색상
* `--color-text-muted`: 아주 연한 힌트용 글자 색상
* `--color-accent`: 가장 돋보이는 포인트 색상 (그라데이션 대신 쨍한 단색)
* `--color-accent-2`: 두 번째 포인트 색상
* `--color-accent-3`: 세 번째 포인트 색상
* `--gradient-primary`: 포인트 단색과 동일한 값 지정 (그라데이션 금지)
* `--gradient-subtle`: 보조 단색 배경 지정 (그라데이션 금지)
* `--gradient-card`: 카드 배경 단색 지정 (그라데이션 금지)
* `--gradient-glow`: `transparent` 지정 (그라데이션 금지)
* `--glass-blur`: `none` 지정 (글래스모피즘 대신 깔끔한 단색 레이아웃 유지)
* `--glass-bg`: 요소를 채울 불투명한 단색 지정
* `--glass-border`: 요소 테두리 단색 지정
